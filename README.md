
A full-stack AI-powered medical chatbot developed as my Final-Year Computer Science Project at Brunel University London.
This project allows users to create accounts, describe their symptoms through a chatbot interface, receive potential condition predictions from a machine-learning service, and access previously saved conversations.
> ⚠️**Warning:** This project was developed for academic and educational purposes only. It is not intended to provide professional medical diagnosis or treatment.

## 🥇 I worked on features that allow users to:

- Create an account and log in to the application.
- Enter symptoms through an interactive chatbot interface.
- Analyse symptom information using a machine-learning service.
- Receive potential condition predictions based on the provided symptoms.
- View multiple predicted conditions.
- Save conversations to individual user accounts.
- Access previous chat sessions and chat history.
- Receive treatment and advice information associated with predicted conditions.
- Use a full-stack system connecting the frontend, Java backend, database and Python AI service.

## 🤖 Chatbot Features

- **User Authentication:** supports user registration and login functionality.
- **Symptom Analysis:** processes symptoms entered through the chatbot interface.
- **Condition Prediction:** sends symptom information to a Python machine-learning service and returns potential condition predictions.
- **Prediction Results:** presents multiple possible conditions rather than relying on a single result.
- **Chat History:** stores messages and previous conversations for individual users.
- **Session Management:** allows users to access previously saved chatbot sessions.
- **Treatment & Advice:** provides stored information related to predicted conditions.
- **Database Storage:** stores user accounts, chat sessions, messages and related application data.

## 🛠️ Technologies

- **Frontend:** React, JavaScript/JSX, React Router, Vite, HTML and CSS.
- **Backend:** Java, Spring Boot, REST APIs, Spring Data JPA, Hibernate and Maven.
- **AI & Machine Learning:** Python, FastAPI, scikit-learn and pandas.
- **Database:** H2 Database.
- **Development Tools:** Visual Studio Code, GitHub and Google Colab.
